The only current plan and acceptance gates are in [ROADMAP.md](../../../ROADMAP.md). Canonical subsystem details are indexed in [docs/README.md](../../README.md).

They may describe deleted HTTP, Qt, MusicXML input or compatibility APIs; those descriptions reflect historical states only. Do not revive them to fix current failures.

If old internal links no longer resolve after archiving, use Git history or the archived relative path. New documentation should link to canonical source modules and the current roadmap instead.
